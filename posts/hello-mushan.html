我是谁？

我叫 MuSHAN，目前是深圳一名高一学生，也是一名全栈技术爱好者。

从今年4月开始，我利用周末时间，从零开始独立开发了一个完整的网站——深圳高中生社区。这是一个专为深圳地区高中生打造的学习交流平台，包含了用户系统、帖子互动、圈子社交、线上自习室等十多个功能模块。

有人问我：为什么要做这件事？

原因如下：我发现身边的同学有很多话想说——想找学习搭子、想分享考试经验、想吐槽学校食堂——但缺少一个真正属于我们深圳高中生自己的交流空间。QQ群太吵，朋友圈太杂，贴吧太乱。所以我就想：为什么不自己做一个呢？

于是便孕育出了这个社区。

我做了什么？

经过两个月的时间，目前项目主体功能已经完善。

技术栈：Node.js + Express + PostgreSQL 做后端，原生 HTML/CSS/JS 写前端，用 Git 做版本管理，托管在 GitHub Pages。

已实现的功能：

  • 完整的用户系统（注册/登录/个人资料/头像上传）
  • 帖子发布、编辑、删除，支持分类和标签
  • 点赞、收藏、回复、搜索
  • 举报与反馈系统
  • 实时通知系统（点赞/回复/关注等事件触发小红点）
  • 管理员仪表盘（数据统计 + 折线图 + 内容审核）
  • 关注系统与动态流
  • 圈子系统（5人联合创建机制）
  • 线上自习室（按行政区划分 + 番茄钟计时 + 实时同步）
  • 完整的移动端适配

项目已经在 GitHub 开源，仓库地址：MuSHANw/szhss-community

我还做了什么？

在开发社区的过程中，我发现很多社团和班级也想有自己的官网，但外面的建站公司报价太高，动辄几百上千。

于是，我发起了一个小项目——橡树建站（深圳高中生技术支援计划）。

这是为深圳各高中的社团、学生会、班级提供极低价的网站制作服务：

  • 体验版 10元：单页面宣传站，1-2天交付
  • 标准版 首次25元：多页面完整站点，含表单和教程

如果你或者你们社团需要，可以通过微信/邮箱等方式联系我。

这个博客会写什么？

这里会记录我的技术学习过程、项目开发故事、以及一些对同龄人可能有用的经验分享。

比如：

  • 一个高中生如何从零开始学全栈开发
  • 开发中踩过的坑和解决思路
  • 如何用最低成本（甚至零成本）部署自己的网站
  • 学生开发者如何平衡学业和项目

如果你也是正在学技术的同学，欢迎一起交流～
